Lab rules

  • Own the data

    Your work lives in plain formats on storage you control. Leaving should be a copy command.

  • Keep it small

    Pick the version with fewer dependencies, because every one you add is another thing to update and debug.

  • Open by default

    We publish the source under permissive licences and work in public, rough edges included.

  • People first, agents welcome

    We build for people first. Agents use a separate interface, such as the MCP server in HoldMyDocs.
